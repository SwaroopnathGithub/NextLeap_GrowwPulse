Sources & Methodology

Data source

Reviews were scraped from the Google Play Store listing for Groww (app ID com.nextbillion.groww, India store) using the google-play-scraper Python library, sorted newest-first, paginated until the 12-week cutoff was reached.

  • Window: 2026-07-21 to 2026-10-14 (12 weeks)
  • Sample size: 12,637 reviews
  • Fields captured: review ID, username, star score, timestamp, review text, thumbs-up count, app version, developer reply (if any)

Theme tagging

Themes were assigned by keyword matching against the review text (case-insensitive substring match), not LLM classification. A review can match more than one theme. The keyword groups used:

Treat theme percentages as directional signal (what's recurring and how often it's mentioned), not precise topic-model output.

Pipeline

The full pipeline, in order:

  1. Scrape — scripts/scrape_reviews.py pulls reviews via the Play Store API wrapper and filters to the 12-week window.
  2. Analyze — scripts/analyze_reviews.py and scripts/weekly_pulse_data.py compute rating distributions, theme frequencies, and week-over-week trends.
  3. Draft — the computed stats + representative quotes feed an n8n workflow where a Groq-backed LLM drafts the weekly pulse and fee explainer.
  4. Approve — the workflow pauses at a human approval gate before anything is written anywhere.
  5. Publish — once approved, the content is appended to a tracking Google Doc and queued as a Gmail draft (never auto-sent). This site is the static, always-visible version of the same deliverables.

Limitations

  • Keyword matching will miss paraphrased complaints and can occasionally mis-tag a theme (e.g., "order" matching casual phrasing unrelated to trade orders).
  • Reviews are self-selected — users who had a frustrating experience are more likely to leave a review than satisfied silent users, so absolute percentages likely overstate real-world incidence even if they're useful for relative theme ranking.
  • Fee figures quoted (₹24 DP charge, ₹5/trade) are what reviewers reported, not independently verified against Groww's official published rates.
